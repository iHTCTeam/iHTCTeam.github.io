<section lang="en" markdown="1">

iRootWise supports **`irootwise://`** links for Shortcuts, widgets, Siri, Control Center, and Home Screen actions.

## Link format

```
irootwise://{host}?{params}
```

## Daily & reading

| URL | Opens |
|-----|-------|
| `irootwise://daily` or `today` | Daily Tan |
| `irootwise://random` | Random passage |
| `irootwise://passage?id=1` (`tan`; host may be numeric) | Passage (`focus=` char offset, `speak=1` to recite) |
| `irootwise://last-read` (`lastread`) | Continue last read |
| `irootwise://reading-history` (`history`) | Reading history |
| `irootwise://notes` | Notes |
| `irootwise://mastered` | Mastered |
| `irootwise://home` | Home (clear stack) |

## Browse & study

| URL | Opens |
|-----|-------|
| `irootwise://categories` (`browse`) | Browse |
| `irootwise://theme?id=` | Theme list |
| `irootwise://section?id=` | Edition section list |
| `irootwise://famous` (`lines`) | Famous lines |
| `irootwise://favorites` (`fav`) | Favorites |
| `irootwise://search?q=` | Search |
| `irootwise://course` (`courses`) | Course list |
| `irootwise://course?id=&day=` | Course / specific day |
| `irootwise://meditation` (`sit` / `breathe`; optional `preset=`) | Meditation |
| `irootwise://insight?id=` (`ai`) | Insight (no id → today) |

## Settings & guides

| URL | Opens |
|-----|-------|
| `irootwise://settings` | Settings |
| `irootwise://usage-guide` | Usage guide |
| `irootwise://widget-guide` | Widget guide |
| `irootwise://shortcuts-guide` | Shortcuts guide |
| `irootwise://feature-guide` | Feature tour |
| `irootwise://home-shortcuts` | Home Screen quick actions |
| `irootwise://feedback` (`mail`) | Feedback |
| `irootwise://in-app-review` (`review`) | Rate prompt |

Theme / section / famous / favorites pages can copy their deep link via **List options → This list**.

</section>
