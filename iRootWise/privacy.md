<section lang="en" markdown="1">

iHTC Studio (formerly iHTCTeam) built iRootWise (爱菜根谭 / 愛菜根譚).

## Summary

**Data Not Collected by iHTC Studio.** Core reading, sit, and courses work **without sending your data to iHTC Studio**. **No account. No ads. No analytics SDK.** The *Caigentan* library is **bundled on your device**. Optional **iCloud Sync** uses **your private iCloud**. **Meditation statistics stay on-device only** and are not mirrored to iCloud.

## Data Stored on Your Device

| Data | Purpose |
|------|---------|
| Passage library | Bundled text, vernacular, appreciation, English, glossary |
| Favorites, lists, notes, mastery, history | Your reading state |
| Course progress & streaks | Day check-ins and continuous practice |
| Meditation sessions & totals | Local practice log (not iCloud-synced) |
| Preferences | Theme, accent, reading language, notifications, Live Activity, Spotlight |

## Network

After install, **everyday use does not require the internet**. Opening App Store pages, sending email feedback, completing an optional tip, writing optional Apple Mindfulness minutes, or using Insight when a system model must download uses **Apple** or **your mail app** — not an iHTC Studio backend for scripture.

## iCloud Sync (optional)

When enabled and signed into iCloud, favorites, lists, notes, mastery, history, course marks, and streaks may sync via your private iCloud key-value store. **Meditation history and cumulative sit stats are excluded.**

## Permissions

| Permission | When | Why |
|------------|------|-----|
| Notifications | Daily Tan / lesson reminders / sit end | Local scheduling only |
| iCloud | Optional sync | Sync non-meditation progress |
| Health (Mindfulness) | Optional, off by default | Write mindfulness minutes you choose |
| Photos (add) | Save share cards | On-device images you choose |
| Spotlight | Optional, off by default | Index passages on device |

<section lang="zh-CN" markdown="1">

爱火腿肠工作室（iHTC Studio；原 iHTCTeam）开发了爱菜根谭。

## 摘要

**iHTC Studio 不收集数据。** 核心品读、静坐与课程 **无需向 iHTC Studio 发送你的数据**。**无账号、无广告、无分析 SDK。** 《菜根谭》语料 **内置在设备本地**。可选 **iCloud 同步** 使用 **你的私有 iCloud**。**静坐统计刻意仅本机**，不同步到 iCloud。

## 设备本地存储

| 数据 | 用途 |
|------|------|
| 篇章库 | 内置原文、白话、赏析、英译、注释 |
| 收藏、清单、心得、掌握、历史 | 你的阅读状态 |
| 课程进度与连续打卡 | 日课与习惯 |
| 静坐明细与累计 | 本机练习记录（不同步 iCloud） |
| 偏好设置 | 主题、强调色、阅读语言、通知、实时活动、Spotlight |

## 网络

安装后，**日常使用不需要联网**。打开 App Store、发送反馈邮件、完成可选打赏、可选写入 Apple 正念分钟，或悟道在系统需要下载模型时，会使用 **Apple** 或**你的邮件应用**——经文本身不经过 iHTC Studio 后端。

## iCloud 同步（可选）

开启并登录 iCloud 后，可通过私有 iCloud 键值存储同步收藏、清单、心得、掌握、历史、课程打卡与连续天数。**静坐明细与累计时长排除在外。**

## 权限

| 权限 | 时机 | 原因 |
|------|------|------|
| 通知 | 每日一谭 / 日课提醒 / 静坐结束 | 仅本地调度 |
| iCloud | 可选同步 | 同步非静坐进度 |
| 健康（正念） | 可选，默认关 | 写入你选择的正念分钟 |
| 照片（添加） | 保存分享卡 | 仅保存你选择的本机图片 |
| Spotlight | 可选，默认关 | 在本机索引篇目 |

## 联系

[AppleOSer@gmail.com](mailto:AppleOSer@gmail.com)
