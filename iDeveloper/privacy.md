<section lang="en" markdown="1">

**Last updated:** July 29, 2026

iHTC Studio ("we", "us" or "our"; formerly iHTCTeam) built **iDeveloper** (also known as "爱开发者" / "愛開發者", Bundle ID `com.iHTCboy.iDeveloper`). This Privacy Policy explains what data is (and is not) handled when you use the app. **Apple App Review** and users may rely on this page as the public privacy URL.

## Summary (Apple Privacy Nutrition Label alignment)

| Topic | Our practice |
|-------|----------------|
| Account | **Not required** |
| Data collection by iHTC Studio | **Data Not Collected** — we do **not** operate a backend that receives your tool inputs or personal data |
| Network | Tools and cheat sheets work **offline** by default. Network-capable tools only send a request when **you** start one |
| Analytics / ads / tracking | **None** — no third-party analytics, advertising, or tracking SDKs |
| Optional Apple services | **iCloud** (your private KVS), **StoreKit** tipping, system Share destinations you choose, widgets / Live Activities / Siri delivered by Apple |

## Data Collection

We do **not** collect, sell, or share personal information for advertising or analytics. Your inputs, outputs, favorites, history, and snippets stay on your device (and optionally in **your** iCloud). They are never uploaded to iHTC Studio servers because **we do not run such servers for this app**.

## How the App Works

- **Bundled tools & references** — Engines and cheat-sheet JSON ship inside the app / widget / share extension bundles.
- **On-device processing** — Formatting, encoding, crypto helpers, regex, and most utilities run locally.
- **Opt-in networking** — If a tool needs the internet, the UI shows a prompt; the request is initiated only by your action and goes to the destination host for that tool — not through an iHTC Studio proxy.
- **Share extension** — Shared text/payloads are handed off via App Group `group.com.iHTCboy.iDeveloper` on your device.
- **Widgets & Live Activity** — Display snapshots of content you already opened or timers you started, via App Group / ActivityKit.
- **Optional tip** — Consumable **StoreKit** purchase processed by Apple.

## Data Stored on Your Device

| Data | Purpose |
|------|---------|
| Tool catalog & reference library | Offline tools and cheat sheets |
| Favorites / recent tools | Quick access |
| Operation history | Restore previous inputs/outputs |
| Snippets | Reusable fragments you save |
| Share inbox buffers | Temporary handoff from Share / Send to Tool |
| Appearance & prefs | Theme, accent, language, tabs, widgets |
| Focus / Live Activity state | Timer display |
| Onboarding & rating prompts | Welcome / review UX |

## iCloud Sync (Optional)

If enabled, selected preferences / workflow state may sync through Apple’s **`NSUbiquitousKeyValueStore`** tied to **your Apple ID**. Sync traffic goes to **Apple iCloud**, not to iHTC Studio.

## Permissions

iDeveloper requests permissions only when a feature needs them (for example Photo Library if a tool saves an image you export, or network when you run a network tool). We do **not** request Tracking, Contacts, or precise Location for analytics.

## Contact

[AppleOSer@gmail.com](mailto:AppleOSer@gmail.com)

| 主题 | 我们的做法 |

我们**不**为广告或分析收集、出售或共享个人信息。输入、输出、收藏、历史与片段留在你的设备（以及可选的**你的** iCloud），不会上传到 iHTC Studio 服务器。

- **主动联网** — 需要网络的工具会提示；请求由你触发，直达该工具的目标主机，不经过 iHTC Studio 代理。
- **分享扩展** — 通过 App Group `group.com.iHTCboy.iDeveloper` 本机投递。
- **小组件与实时活动** — 展示你已打开的内容或已启动的计时。
- **可选打赏** — Apple StoreKit 处理。

## 设备本地存储

| 数据 | 用途 |
|------|------|

| 操作历史 | 恢复输入输出 |
| 代码片段 | 可复用片段 |
| 分享投递缓冲 | Share / 发送到工具临时交接 |
| 外观与偏好 | 主题、强调色、语言、Tab、小组件 |
| 专注 / 实时活动状态 | 计时展示 |
| 引导与评分提示 | 欢迎 / 评价体验 |

## iCloud 同步（可选）

开启后，部分偏好 / 工作流状态可通过与**你的 Apple ID** 绑定的私有 iCloud 键值存储同步。流量走 **Apple iCloud**，不经过 iHTC Studio。

## 权限

仅在功能需要时请求（例如某工具导出图片时的相册权限，或你运行联网工具时的网络）。我们**不**为分析请求追踪、通讯录或精确位置。
