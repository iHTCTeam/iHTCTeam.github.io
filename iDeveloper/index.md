**Ship faster. Look things up without leaving your pocket.**

iDeveloper (爱开发者 / 愛開發者) is a **developer pocket studio** for iPhone, iPad and Mac — not another random tool pile. **No account required.** Use **163 offline tools** across 13 categories (JSON / XML / YAML / SQL, Base64 / JWT, Hash / AES, timestamps / Cron, regex, colors, HTTP / Curl, code converters, Apple helpers, and more) plus **14 bilingual cheat-sheet topics** (~420 entries). Keep **favorites, history, and snippets**; route text via **Share** with smart suggestions; add **widgets**, **Focus Live Activity**, **Siri & Shortcuts**, and Control Center. **No ads. No tracking. Network tools only run when you start a request.**

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id1240856775) and open **iDeveloper**.
2. Complete the **welcome guide** (tools → references → workflow → system features → privacy).
3. Replay anytime: **Settings → Help → Feature Guide**.
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Open a tool and get a result

1. From **Home** or **Browse**, pick a tool (e.g. JSON, Base64, Timestamp, Regex).
2. Paste or type input — or use **Send to Tool** / the **Share** extension with smart recommendations (Suggested → Recent → All).
3. Run the tool, copy the output, and optionally save a **snippet** or restore from **history** (dual-pane tools can restore both sides).
4. Related tools appear as light links when they make sense for the next step.

### 3. Use the offline cheat sheets

1. Open the **Reference** center or jump to a topic (HTTP / Headers / MIME / Git / Docker / Cron / SQL / Regex / SSH / npm / Kubernetes / Linux / JWT / TLS).
2. Search globally or open a specific entry via deep link `ideveloper://reference?id=…`.
3. Pin favorites and open daily reference widgets on the Home Screen.

### 4. Build a workflow you’ll actually keep

1. Star tools and reference entries you use weekly.
2. Revisit **Recent** and **History** instead of re-typing.
3. Save reusable **snippets** for paste-ready fragments.
4. From another app, Share into iDeveloper — the picker ranks the best-matching tools first.

### 5. Widgets, Focus Live Activity & Siri

1. Long-press Home Screen → **Edit Widgets** → add Daily Reference / Quick Tools / Timestamp / Favorites (Home & Lock sizes where available).
2. Start a **Focus** timer to show **Live Activity** on Lock Screen / Dynamic Island.
3. Ask **Siri** or use Shortcuts for search, favorites, focus, and common tools.
4. Configure Home Screen quick actions and Control Center controls (iOS 18+).

### 6. Appearance & privacy

1. Choose theme, accent color (9 options), language (EN / 简 / 繁), and text size.
2. Toggle tab visibility; optionally let widgets follow the app theme; pick alternate app icons.
3. Core tools and cheat sheets work **offline**. Tools that need the network show a clear prompt and only request when **you** tap.
4. Optional tip (StoreKit) never unlocks paywalled content and never creates an account.
