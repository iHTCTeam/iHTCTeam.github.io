**One stratagem a day. Clarity for a lifetime.**

iArtOfWar (爱兵法 / 愛兵法) is an **immersive strategy-classics learning studio** — not another plain text dump. **No account required.** **174** works ship on your device: *The Art of War*, *Sun Bin*, the *Wujing* classics, and the *Thirty-Six Stratagems*, with **bilingual reading**, **vernacular**, and **101** famous lines / stratagems. **Recite** with a mixed-language playback matrix; practice in the **Strategy classroom**; open a contextual **Daily Stratagem**. Export **share cards**, add **widgets**, optional **Reading Live Activity**, **Siri & Shortcuts**, and optional **iCloud**. **No ads. No tracking. Data Not Collected.**

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id6795595036) and open **iArtOfWar**.
2. Complete the **welcome guide** (brand → bilingual reading → recite → study → system features → privacy).
3. Replay anytime: **Settings → Help → Feature Guide**.
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Read today’s stratagem on Home

1. Open the **Home** tab.
2. The **Daily Stratagem** hero shows today’s passage; tap to open detail.
3. Optional: turn on **Daily Stratagem notifications** in **Settings** (local scheduling only; festivals follow the lunar calendar).
4. Continue reading, famous lines, streaks, and shortcuts (including **Hunt**) are one tap away.

### 3. Browse & search

1. Open **Browse** (on by default).
2. Explore **books** (including the Wujing collection), **six stratagem suites**, **Six Tao volumes**, authors, famous lines, and all passages. Book pages for 三十六计 / 六韬 / 尉缭 / 孙膑 support chip filters by suite or volume.
3. Use **Search** for titles, lines, and authors (Simplified / Traditional friendly).
4. Star passages into **Favorites**; build personal **strategy lists** (兵单). Favorites tab is **on by default**.

### 4. Bilingual reading & share cards

1. On detail, choose **bilingual / Chinese only / English only**; toggle vernacular and English independently.
2. Try **immersive reading**, font size, and **segmented reading** for long chapters. Sun Bin fragmentary texts show a one-time note at the top of the original text.
3. Open **Share Card (谋卡)** → preview → save to Photos (add-only) or system share.
4. Optional: enable **Reading Live Activity** on iPhone (must start in foreground).

### 5. Recite (诵读)

1. On detail, tap **Recite** — or open the Recitation studio.
2. Follow **paragraph highlighting** while listening.
3. In **Settings → Reading & Recitation**, set the **playback content matrix** (title / author / body × original / vernacular / English) — independent from what you *see*. Presets and a quick sheet are available on detail / immersive / recite screens.
4. Optional: silent-mode playback, background audio + Now Playing, continuous play (segment then chapter), keep screen on while speaking. When a queue finishes, you can jump into the Strategy classroom.

### 6. Strategy classroom (谋略学堂)

1. Open **Study** from Home / `iartofwar://study` / Shortcuts.
2. Modes: **Recitation**, **Fill-blank**, **Self-check**, **Quiz**; practice a single segment or a batch from favorites / lists.
3. Play **Hunt (寻谋)** — keyword discovery game.
4. Track mastery levels and streaks.

### 7. Widgets, Siri & Home Screen shortcuts

1. Long-press Home Screen → **Edit Widgets** → add **Daily Stratagem / Famous Line / Study Progress / Favorites**.
2. Ask **Siri** for today’s stratagem, recite, random, favorites, or search. Book / theme intents are available in Shortcuts.
3. Configure up to **4 Home Screen quick actions** in **Settings → Shortcuts**.
4. Control Center controls (iOS 18+) include Today / Random / Search / Study / Hunt and more.

### 8. Privacy & sync

1. Library, reading, recite (system TTS), study, widgets, and local notifications work **fully offline** after install.
2. Optional **iCloud Sync** mirrors favorites, lists, history, mastery, and streaks through **your private iCloud**.
3. Tip the developer (optional StoreKit) never unlocks paywalled content and never creates an account.

## 保姆级上手教程

### 1. 第一次打开

1. 从 [App Store](https://apps.apple.com/app/id6795595036) 安装并打开**爱兵法**。
2. 跟随欢迎引导（品牌 → 对照品鉴 → 诵读 → 学堂 → 系统能力 → 隐私）。
3. 之后可随时：**设置 → 帮助 → 功能引导** 重播。
4. **设置 → 帮助** 内还有**使用说明 / 小组件指南 / 快捷指南**。

### 2. 在首页看「每日一计」

1. 打开**首页** Tab。
2. Hero 卡片展示今日篇目，点按进入详情。
3. 想每天提醒：到设置打开每日通知并设定时间（**仅本机调度**；节日按**农历**）。
4. 首页还可继续阅读、看名句、打卡，并进入**寻谋**等快捷入口。

### 3. 分类浏览与搜索

1. 打开**分类** Tab（默认开启）。
2. 浏览**书目**（含武经合集）、**六套计策**、**六韬六卷**、作者、名句与全部篇目。三十六计 / 六韬 / 尉缭 / 孙膑书内可用芯片按套或卷编筛选。
3. 用**搜索**查标题、正文、作者（简繁友好）。
4. 收藏篇目，并整理个人**兵单**。收藏 Tab **默认开启**。

### 4. 对照品鉴与谋卡

1. 详情页切换**对照 / 仅中 / 仅英**；白话与英译可分别开关。
2. 进入**沉浸阅读**，可调字号；长篇支持**分段阅读**。孙膑残简篇会在原文区顶部一次提示。
3. 打开**谋卡** → 预览 → 存入相册（仅「添加照片」）或系统分享。
4. iPhone 可打开**品读实时活动**（须在前台启动）。

### 5. 诵读（怎么听、怎么混读）

1. 在详情点**诵读**，或进入诵读工作台。
2. 跟随**段级高亮**听读。
3. 到 **设置 → 阅读与诵读** 设置**播放内容矩阵**（标题/作者/正文 × 原文/白话/英文）——与屏幕显示解耦；详情 / 沉浸 / 诵读也有快捷面板与预设。
4. 建议按需打开：静音外放、后台播放与锁屏播控、连续播放（先段后篇）、播放时屏幕常亮。队列播完可一键进入谋略学堂。

### 6. 谋略学堂（怎么练到掌握）

1. 从首页或 `iartofwar://study` 进入。
2. 四种模式：**背诵 / 填空 / 自测对照 / 测验**；可练本段，也可从收藏 / 兵单批量练习。
3. 玩玩**寻谋**小游戏。
4. 掌握度分级配合打卡连续天数。

### 7. 小组件、Siri、主屏快捷

1. 长按主屏幕 → **编辑** → **添加小组件** → 搜索「爱兵法」。
2. 可选：**每日一计 / 名句 / 掌握进度 / 收藏**。
3. 对 Siri 说今日一计、随机、诵读、收藏或搜索；快捷指令中还可选用书目 / 计套意图。
4. **设置 → 快捷**：最多 4 个主屏长按快捷；iOS 18+ 还可加控制中心控件（含寻谋）。

### 8. 数据、同步与隐私

1. 语料在 App 内，**日常使用不需要网络**。
2. **设置 → 数据 → iCloud 同步**（可选）：同步收藏、兵单、浏览记录、掌握度与打卡——走**你的私有 iCloud**。
3. 「打赏开发者」为可选内购，**不解锁功能、不创建账号**。
4. 完整说明见 [隐私政策](privacy)。
