<section lang="en" markdown="1">

iZen supports **`izen://`** links for Shortcuts, widgets, Control Center, Siri, and Home Screen actions.

## Link format

```
izen://{host}?{params}
```

## Core navigation

| URL | Opens |
|-----|-------|
| `izen://home` | Home |
| `izen://browse` | Browse |
| `izen://browse/instant` | Instant recovery layer |
| `izen://browse/rebuild` | Daily rebuild layer |
| `izen://browse/root` | Root relief layer |
| `izen://favorites` | Favorites |
| `izen://settings` | Settings |
| `izen://search` | Search |
| `izen://daily` | Daily Zen |
| `izen://continue` | Continue last session |

## Workstations & tools

| URL | Opens |
|-----|-------|
| `izen://breathe` | Breathing desk (optional `/id`) |
| `izen://sos` | SOS / instant recovery pack |
| `izen://soundscape` | Procedural soundscape mixer |
| `izen://journal` | Mood journal |
| `izen://assessment` | 1-minute stress assessment |
| `izen://stats` | Recovery statistics |
| `izen://three-tasks` | Daily three tasks |
| `izen://cognitive` | Cognitive reframe |
| `izen://help` | Crisis helpline directory |

## Content deep links

| URL | Opens |
|-----|-------|
| `izen://practice/<id>` | Practice detail |
| `izen://quote` or `izen://quote/<id>` | Quote detail |
| `izen://science/<id>` | Science article detail |

## Guides & system

| URL | Opens |
|-----|-------|
| `izen://usage-guide` | Usage guide |
| `izen://widget-guide` | Widget guide |
| `izen://shortcuts-guide` | Shortcuts guide |
| `izen://feature-guide` | Feature tour |
| `izen://feedback` | Feedback email |
| `izen://in-app-review` | Rate prompt |

Cold/warm launches may buffer deep links until onboarding finishes or the library is ready.

</section>
