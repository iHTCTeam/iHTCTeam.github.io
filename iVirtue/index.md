**One rule a day. Character for a lifetime.**

iVirtue (爱弟子规 / 愛弟子規) is an **immersive Di Zi Gui learning & practice studio** for families and educators — not another plain text dump. **No account required.** All **90 stanzas** across seven chapters ship on your device with **vernacular**, **natural English**, practice tips, and selected life stories. **Read** side by side; **recite** with line highlighting; train in the **Virtue classroom**; keep a **daily practice streak**. Export **share cards**, add **widgets**, optional **Reading Live Activity**, **Siri & Shortcuts**, and optional **iCloud**. **No ads. No tracking. Data Not Collected.**

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id6796000304) and open **iVirtue**.
2. Complete the **6-page welcome guide** (brand → bilingual reading → recite → virtue study → practice → privacy).
3. Replay anytime: **Settings → Help → Feature Guide**.
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Read today’s rule on Home

1. Open the **Home** tab.
2. The **Daily Rule** hero shows today’s stanza; tap to open detail.
3. Follow the **practice tip** (践行提示) and check in for your streak. Open **practice history** to review past days.
4. Optional: turn on **Daily Rule notifications** in **Settings → Daily** (local scheduling only). Detail-page practice panel can be hidden there too.

### 3. Browse & search

1. Open **Browse** (on by default; can be hidden in Settings).
2. Explore **seven chapters** (总叙 / 入则孝 / 出则弟 / 谨 / 信 / 泛爱众 / 亲仁 / 余力学文) and **virtue themes** (孝 / 悌 / 谨 / 信 …).
3. Use **Search** for Chinese, English, or **tone-less pinyin** (e.g. `xiao`, `fumu`).
4. Star stanzas into **Favorites**; build personal **rule lists** (规单). Favorites tab is **on by default**; if you hide it, use the heart on Home.

### 4. Bilingual reading & share cards

1. On detail, choose **bilingual / Chinese only / English only**; toggle vernacular and English independently.
2. Chapter-level vernacular appears as a **guide** (题解) when verse-level vernacular exists — keep it folded if you want a cleaner page.
3. Adjust **font size** (standard / family / elder). Try immersive reading and segmented pages for longer stretches.
4. Open **Share Card** → preview → save to Photos (add-only) or system share.

### 5. Recite (朗读)

1. On detail, tap **Recite** — or open the Recitation studio.
2. Follow **line-level highlighting** while listening.
3. In **Settings → Recitation**, set the **playback content matrix** (title / author / body × original / vernacular / English) — independent from what you *see*.
4. Optional: silent-mode playback, background audio + Now Playing, continuous play, sleep timer, keep screen on, Live Activity (start in foreground).

### 6. Virtue classroom & practice (美德学堂 · 践行)

1. Open **Study** from Home / `ivirtue://study` / Shortcuts.
2. Modes: **Recitation**, **Fill-blank**, **Self-check**, **Quiz**; plus **Hunt (寻规)**.
3. Track mastery levels; practice a single stanza or a batch from favorites / lists.
4. Use **practice tips** and the Home streak so learning becomes daily habit — not just reading.

### 7. Widgets, Siri & Home Screen shortcuts

1. Long-press Home Screen → **Edit Widgets** → add **Daily Rule / Famous Line / Study Progress / Favorites**.
2. Ask **Siri** for today’s rule, recite, random, favorites, practice, or search.
3. Configure Home Screen quick actions in **Settings → Shortcuts**.
4. Control Center controls (iOS 18+) include Today / Random / Search / Study / Practice / Hunt and more.

### 8. Privacy & sync

1. Library, reading, recite (system TTS), study, widgets, and local notifications work **fully offline** after install.
2. Optional **iCloud Sync** mirrors favorites, lists, history, mastery, and streaks through **your private iCloud**.
3. Tip the developer (optional StoreKit) never unlocks paywalled content and never creates an account.

## 保姆级上手教程

### 1. 第一次打开

1. 从 [App Store](https://apps.apple.com/app/id6796000304) 安装并打开**爱弟子规**。
2. 跟随 **6 页欢迎引导**（品牌 → 对照品读 → 朗读 → 美德学堂 → 践行 → 隐私）。
3. 之后可随时：**设置 → 帮助 → 功能引导** 重播。
4. **设置 → 帮助** 内还有**使用说明 / 小组件指南 / 快捷指南**。

### 2. 在首页看「每日一规」

1. 打开**首页** Tab。
2. Hero 卡片展示今日韵段，点按进入详情。
3. 看**践行提示**，完成打卡，积累连续天数；可打开**践行历史**按日回顾。
4. 想每天提醒：到 **设置 → 每日** 打开通知并设定时间（**仅本机调度**）；详情页践行面板也可在此关闭。

### 3. 分类浏览与搜索

1. 打开**分类** Tab（默认开启，可在设置中隐藏）。
2. 浏览**七篇章**与**美德主题**（孝 / 悌 / 谨 / 信 / 爱众 / 亲仁 / 学文等）。
3. 用**搜索**查中文、英文，或**无调拼音**（如 `xiao`、`fumu`）。
4. 收藏韵段，并整理个人**规单**。收藏 Tab **默认开启**；若关闭，仍可从首页右上角爱心进入。

### 4. 对照品读与分享卡

1. 详情页切换**对照 / 仅中 / 仅英**；白话与英译可分别开关。
2. 有逐段白话时，篇级白话以**题解**展示（可折叠，避免与句下白话重复）。
3. 调节**字号**（标准 / 亲子 / 长辈）；可进沉浸阅读，长文支持分段。
4. 打开**分享卡** → 预览 → 存入相册（仅「添加照片」）或系统分享。

### 5. 朗读（怎么听、怎么混读）

1. 在详情点**朗读**，或进入朗读工作台。
2. 跟随**句级高亮**听读。
3. 到 **设置 → 朗读** 设置**播放内容矩阵**（标题/作者/正文 × 原文/白话/英文）——与屏幕显示解耦，可混读多语种。
4. 建议按需打开：静音外放、后台播放与锁屏播控、连续播放、睡眠定时、播放时屏幕常亮、朗读实时活动（须在前台启动）。

### 6. 美德学堂与践行（怎么练到养成）

1. 从首页或 `ivirtue://study` 进入学堂。
2. 四种模式：**背诵 / 填空 / 自测 / 测验**；另有**寻规**。
3. 掌握度分级；可练单段，也可从收藏 / 规单批量练习。
4. 用践行提示 + 首页打卡，把「读过」变成「做到」。

### 7. 小组件、Siri、主屏快捷

1. 长按主屏幕 → **编辑** → **添加小组件** → 搜索「爱弟子规」。
2. 可选：**每日一规 / 名句 / 掌握进度 / 收藏**。
3. 对 Siri 说今日一规、随机、朗读、收藏、践行或搜索。
4. **设置 → 快捷**：配置主屏长按快捷；iOS 18+ 还可加控制中心控件（含践行 / 寻规）。

### 8. 数据、同步与隐私

1. 语料在 App 内，**日常使用不需要网络**。
2. **设置 → 数据 → iCloud 同步**（可选）：同步收藏、规单、浏览记录、掌握度与打卡——走**你的私有 iCloud**。
3. 「打赏开发者」为可选内购，**不解锁功能、不创建账号**。
4. 完整说明见 [隐私政策](privacy)。
