<section lang="en" markdown="1">

iVirtue supports **`ivirtue://`** shortcut links (URL scheme). Cold start and Home Screen shortcuts are delivered through a unified buffer so links are not opened twice after onboarding.

## Link format

```
ivirtue://{host}?{params}
```

## Stanzas & discovery

| URL | Opens |
|-----|-------|
| `ivirtue://home` | Home |
| `ivirtue://daily` | Today’s Daily Rule |
| `ivirtue://practice` | Practice / check-in entry |
| `ivirtue://streak` | Streak |
| `ivirtue://random` | Random stanza |
| `ivirtue://passage?id={id}` | Stanza detail |
| `ivirtue://author?id={id}` | Author detail |
| `ivirtue://recite` / `ivirtue://recite?id={id}` | Recite flow |
| `ivirtue://favorites` | Favorites |
| `ivirtue://famous` | Famous lines |
| `ivirtue://search` / `ivirtue://search?q={query}` | Search |
| `ivirtue://study` | Virtue classroom |
| `ivirtue://hunt` | Hunt (寻规) |
| `ivirtue://mastered` | Mastered |
| `ivirtue://categories` | Browse |
| `ivirtue://collection?name=` | Chapter / collection |
| `ivirtue://theme?id=` | Virtue theme |
| `ivirtue://last-read` | Last read |
| `ivirtue://reading-history` | Reading history |
| `ivirtue://notes` | Notes |

## Settings & guides

| URL | Opens |
|-----|-------|
| `ivirtue://settings` | Settings |
| `ivirtue://daily-settings` | Daily Rule settings |
| `ivirtue://home-shortcuts` | Home Screen quick actions |
| `ivirtue://usage-guide` | Usage guide |
| `ivirtue://widget-guide` | Widget guide |
| `ivirtue://shortcuts-guide` | Shortcuts guide |
| `ivirtue://feature-guide` | Replay onboarding |
| `ivirtue://tip` | Tip developer |
| `ivirtue://feedback` | Feedback email |
| `ivirtue://in-app-review` | In-app / Store review entry |
| `ivirtue://privacy` | In-app privacy |

## Examples

```
ivirtue://daily
ivirtue://practice
ivirtue://passage?id=1
ivirtue://recite?id=1
ivirtue://study
ivirtue://hunt
ivirtue://search?q=xiao
```

Use these in the Shortcuts app, Home Screen quick actions, widgets, Control Center, or Safari. See also in-app **Settings → Shortcuts Guide**.

</section>
