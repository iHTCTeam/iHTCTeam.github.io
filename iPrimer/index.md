**One chapter a day. Character for a lifetime.**

iPrimer (爱小学 / 愛小學) is an **offline wisdom-growth companion** built around Zhu Xi’s *Xiaoxue* (Primary Learning) — not another plain classics dump. **No account required.** All **388** chapters across **six** volumes ship on your device with **vernacular**, **collected notes**, **tap-to-gloss terms**, and **paragraph-aligned English**. **Recite** with segment highlighting; train in the **Character Study** hall; practice **six guided meditations**; keep a **reflection journal** and daily habit check-ins under **Life Guidance**. Start with contextual **Daily Study**. Export **share cards**, add **six widget types**, optional **Reading / Meditation Live Activity**, **Siri & Shortcuts**, and optional **iCloud**. Library text is curated from public web sources. **No ads. No tracking. Data Not Collected.**

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id6798921004) and open **iPrimer**.
2. Complete the **6-page welcome guide** (brand → study → recite → meditation → guidance → privacy).
3. Replay anytime: **Settings → Help → Feature Guide**.
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Read today’s chapter on Home

1. Open the **Home** tab.
2. The **Daily Study** hero shows today’s chapter with an English preview when the UI is in English; tap to open detail.
3. Explore the three modules: **Classics**, **Meditation**, and **Life Guidance**.
4. Optional: turn on **Daily Study notifications** in **Settings → Daily** (local scheduling only).

### 3. Browse & search

1. Open **Browse** (on by default; can be hidden in Settings).
2. Explore **six volumes** (Establishing Teaching, Relationships, Self-Respect, Antiquity, Fine Words, Good Deeds), authors, famous lines, and all chapters.
3. Use **Search** for Chinese, English, or **tone-less pinyin**.
4. Star chapters into **Favorites**; build personal **study lists** (学单). Favorites tab is **on by default**.

### 4. Bilingual reading & share cards

1. On detail, choose **bilingual / Chinese only / English only**; toggle vernacular, collected notes (Ann.), and English independently.
2. Tap underlined terms for **gloss popovers** (no global toggle). Chapter-level vernacular appears as a **guide** when verse-level vernacular exists.
3. Try **immersive reading**, font size, **segmented reading** for long chapters, and per-chapter **reflection prompts**.
4. Open **Share Card** → preview → save to Photos (add-only) or system share.

### 5. Recite (诵读)

1. On detail, tap **Recite** — or open the Recitation studio.
2. Follow **segment highlighting** while listening.
3. In **Settings → Reading & Speech**, set the **playback content matrix** (title / author / body × original / vernacular / English) — independent from what you *see*.
4. Optional: silent-mode playback, background audio + Now Playing, continuous play, sleep timer, keep screen on, Reading Live Activity (start in foreground).

### 6. Character Study (品格学堂)

1. Open **Study** from Home / `iprimer://study` / Shortcuts.
2. Modes: **Recitation**, **Fill-blank**, **Self-check**, **Quiz**; plus **Hunt (寻句)**.
3. Track mastery levels; practice a single chapter or a batch from favorites / study lists.

### 7. Meditation & Life Guidance

1. Open **Guided Meditation** from Home or `iprimer://meditation` — six offline sessions with breathing animation; optional Meditation Live Activity and Control Center control.
2. Open **Life Guidance** (`iprimer://guidance`) for a **reflection journal** (linkable to Daily Study) and **seven daily habit check-ins** (洒扫应对); streaks tracked separately from study.
3. Optional meditation reminders in **Settings → Practice**.

### 8. Widgets, Siri & Home Screen shortcuts

1. Long-press Home Screen → **Edit Widgets** → add **Daily Study / Famous Line / Favorites / Learning Progress / Meditation Streak / Life Guidance**.
2. Ask **Siri** for today’s chapter, recite, random, favorites, study, meditation, guidance, or search.
3. Configure Home Screen quick actions in **Settings → Shortcuts**.
4. Control Center controls (iOS 18+) include Today / Random / Search / Study / Meditation / Guidance / Hunt and more.

### 9. Privacy & sync

1. Library, reading, recite (system TTS), study, meditation, guidance, widgets, and local notifications work **fully offline** after install.
2. Optional **iCloud Sync** mirrors favorites, study lists, history, mastery, streaks, reflection entries, and habit check-ins through **your private iCloud**.
3. Tip the developer (optional StoreKit) never unlocks paywalled content and never creates an account.

## 保姆级上手教程

### 1. 第一次打开

1. 从 [App Store](https://apps.apple.com/app/id6798921004) 安装并打开**爱小学**。
2. 跟随 **6 页欢迎引导**（品牌 → 研习 → 诵读 → 冥想 → 指导 → 隐私）。
3. 之后可随时：**设置 → 帮助 → 功能引导** 重播。
4. **设置 → 帮助** 内还有**使用说明 / 小组件指南 / 快捷指南**。

### 2. 在首页看「每日一学」

1. 打开**首页** Tab。
2. Hero 卡片展示今日篇章（英文界面会显示英译预览），点按进入详情。
3. 三大模块：**经典**、**静心冥想**、**人生指导**。
4. 想每天提醒：到 **设置 → 每日** 打开通知并设定时间（**仅本机调度**）。

### 3. 分类浏览与搜索

1. 打开**分类** Tab（默认开启，可在设置中隐藏）。
2. 浏览**六卷**（立教、明伦、敬身、稽古、嘉言、善行）、作者、名句与全部篇章。
3. 用**搜索**查中文、英文，或**无调拼音**。
4. 收藏篇章，并整理个人**学单**。收藏 Tab **默认开启**。

### 4. 对照品读与分享卡

1. 详情页切换**对照 / 仅中 / 仅英**；白话、集注「注」与英译可分别开关。
2. 原文中带下划线的词可**点查释义**（无全局开关）。有逐段白话时，篇级白话以**题解**展示。
3. 调节**字号**；可进沉浸阅读，长文支持**分段阅读**；每章有**反思问题**。
4. 打开**分享卡** → 预览 → 存入相册（仅「添加照片」）或系统分享。

### 5. 诵读（怎么听、怎么混读）

1. 在详情点**诵读**，或进入诵读工作台。
2. 跟随**句级高亮**听读。
3. 到 **设置 → 阅读与语音** 设置**播放内容矩阵**（标题/作者/正文 × 原文/白话/英文）——与屏幕显示解耦，可混读多语种。
4. 建议按需打开：静音外放、后台播放与锁屏播控、连续播放、睡眠定时、播放时屏幕常亮、品读实时活动（须在前台启动）。

### 6. 品格学堂（怎么练到掌握）

1. 从首页或 `iprimer://study` 进入学堂。
2. 四种模式：**背诵 / 填空 / 自测 / 测验**；另有**寻句**。
3. 掌握度分级；可练单章，也可从收藏 / 学单批量练习。

### 7. 静心冥想与人生指导

1. 从首页或 `iprimer://meditation` 进入**六套离线冥想**（呼吸动画、可选冥想实时活动与控制中心控件）。
2. `iprimer://guidance` 打开**反思日记**（可关联每日一学篇章）与**洒扫应对七项微习惯打卡**；与学堂连续分开统计。
3. 可在 **设置 → 修习** 打开冥想提醒（可选）。

### 8. 小组件、Siri、主屏快捷

1. 长按主屏幕 → **编辑** → **添加小组件** → 搜索「爱小学」。
2. 可选：**每日一学 / 名句 / 收藏 / 学习进度 / 冥想连续 / 人生指导**。
3. 对 Siri 说今日一学、随机、诵读、收藏、学堂、冥想、指导或搜索。
4. **设置 → 快捷**：配置主屏长按快捷；iOS 18+ 还可加控制中心控件（含冥想 / 指导 / 寻句）。

### 9. 数据、同步与隐私

1. 语料在 App 内，**日常使用不需要网络**。
2. **设置 → 数据 → iCloud 同步**（可选）：同步收藏、学单、浏览记录、掌握度、打卡、反思日记与习惯记录——走**你的私有 iCloud**。
3. 「打赏开发者」为可选内购，**不解锁功能、不创建账号**。
4. 完整说明见 [隐私政策](privacy)。
