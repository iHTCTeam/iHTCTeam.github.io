**One phone. Countless sutras.**

iSutra (爱佛经 / 愛佛經) is an **immersive sutra reading & practice studio** — not another plain text dump. **No account required.** A **144-entry** offline index ships with frequently recited classics (Heart Sutra, Diamond Sutra in 32 divisions, Amitabha Sutra, Medicine Buddha vows, Universal Gate, Dizang in 13 chapters, mantras, Platform Sutra excerpts, Forty-Two Chapters, Eight Awakenings, and more), with **bilingual reading**, **vernacular**, and **101** famous lines. **Recite** with paragraph highlighting; practice in the **Study Hall**; tap the **wooden-fish chant counter**; **copy sutras** with PencilKit tracing (iOS); keep **morning / evening practice** with dedication. Open a contextual **Daily Sutra**. Export **Dharma cards**, add **widgets**, optional **Reading / Chant Live Activities**, **Siri & Shortcuts**, and optional **iCloud**. Texts are for **learning and educational use**. **No ads. No tracking. Data Not Collected.**

**At a glance:** 144-index library · Diamond & Dizang large volumes · bilingual read · recite · chant · copy-sutra · practice · Daily Sutra · 101 lines · Dharma cards · widgets · Control Center · `isutra://` · EN / 简 / 繁.

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id6796014949) and open **iSutra**.
2. Complete the **welcome guide** (brand → bilingual reading → recite → study / chant → practice → privacy).
3. Replay anytime: **Settings → Help → Feature Guide** (`isutra://feature-guide`).
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Read today’s sutra on Home

1. Open the **Home** tab.
2. The **Daily Sutra** hero shows today’s passage; tap to open detail.
3. Optional: turn on **Daily Sutra notifications** in Settings (local scheduling only).
4. Continue reading, famous lines, streaks, and shortcuts (recite / study / hunt / chant / copy / practice) are one tap away.

### 3. Browse & search

1. Open **Browse** (on by default; can be hidden in Settings).
2. Explore **collections** (Prajna / Lotus / Avatamsaka / Pure Land / Ksitigarbha / Esoteric / Chan / Forty-Two / Eight Awakenings), themes, famous lines, translators, and all entries. Large-book shells open a volume catalog.
3. Use **Search** for titles, lines, and vernacular (Simplified / Traditional friendly).
4. Star passages into **Favorites**; build personal **sutra lists** (经单). Favorites tab is **on by default**.

### 4. Bilingual reading & Dharma cards

1. On detail, choose **bilingual / Chinese only / English only**; toggle vernacular, English, and pinyin independently.
2. Try **immersive reading**, vertical layout, font scale, and **segmented pages** for long chapters.
3. Open **Share Card (法卡)** → pick style / ratio → save to Photos (add-only) or system share.
4. Optional: enable **Reading Live Activity** on iPhone (start in foreground).

### 5. Recite (诵经)

1. On detail, tap **Recite** — or open the recitation workbench.
2. Follow **paragraph highlighting** while listening.
3. In **Settings → Reading & Recitation**, set the **playback content matrix** (original / vernacular / English) — independent from what you *see*.
4. Optional: silent-mode playback, background audio + Now Playing, continuous play across chapter parts, keep screen on.

### 6. Study Hall, chant, copy & practice

1. **Study** (`isutra://study`): recitation / fill-blank / self-check / quiz, plus **Hunt (寻经)**.
2. **Chant** (`isutra://count`): wooden-fish counter with goals (27 / 54 / 108 / 1080 or custom), five tones, optional Chant Live Activity.
3. **Copy sutra** (`isutra://copy`, iOS): PencilKit tracing — ink / pen styles, undo, per-line drafts, PNG / PDF export (strokes stay on device).
4. **Practice** (`isutra://practice`): morning / evening checklists and dedication text; optional iCloud for checklist config.

### 7. Widgets, Siri & Home Screen shortcuts

1. Long-press Home Screen → **Edit Widgets** → add **Daily Sutra / Famous Line / Study Progress / Favorites / Today’s Chant**.
2. Ask **Siri** for today’s sutra, recite, random, favorites, study, hunt, chant, copy, or search.
3. Configure Home Screen quick actions in **Settings → Shortcuts**.
4. Control Center controls (iOS 18+) include Today / Random / Search / Study / Hunt / Chant / Practice / Copy and more.

### 8. Privacy & sync

1. Library, reading, recite (system TTS), study, chant, practice, widgets, and local notifications work **fully offline** after install. Copy-sutra is iOS-only and stores strokes locally.
2. Optional **iCloud Sync** mirrors favorites, lists, history, mastery, notes, chant prefs, and practice config through **your private iCloud**.
3. Tip the developer (optional StoreKit) never unlocks paywalled content and never creates an account.

## 保姆级上手教程

### 1. 第一次打开

1. 从 [App Store](https://apps.apple.com/app/id6796014949) 安装并打开**爱佛经**。
2. 跟随欢迎引导（品牌 → 对照品读 → 诵经 → 学堂 / 念诵 → 功课 → 隐私）。
3. 之后可随时：**设置 → 帮助 → 功能引导** 重播（`isutra://feature-guide`）。
4. **设置 → 帮助** 内还有**使用说明 / 小组件指南 / 快捷指南**。

### 2. 在首页看「今日一经」

1. 打开**首页** Tab。
2. Hero 卡片展示今日经文，点按进入详情。
3. 想每天提醒：到设置打开每日通知并设定时间（**仅本机调度**）。
4. 首页还可继续品读、看法语、打卡，并进入诵经 / 学堂 / 寻经 / 念诵 / 抄经 / 功课等入口。

### 3. 分类浏览与搜索

1. 打开**分类** Tab（默认开启，可在设置中隐藏）。
2. 浏览**部类合集**（般若 / 法华 / 华严 / 净土 / 地藏 / 密教 / 禅宗 / 四十二章 / 八觉）、主题、法语、译者与全部经目。大部头壳篇进入分卷目录。
3. 用**搜索**查题名、原文与白话（简繁友好）。
4. 收藏经目，整理个人**经单**。收藏 Tab **默认开启**。

### 4. 对照品读与法卡

1. 详情页切换**对照 / 仅中 / 仅英**；白话、英译、注音可分别开关。
2. 可开竖排沉浸、字号缩放；长章支持**分段翻页**。
3. 打开**法卡** → 选风格 / 比例 → 存入相册（仅「添加照片」）或系统分享。
4. 可选开启**品读实时活动**（需前台启动）。

### 5. 诵经

1. 在详情点**诵经**，或进入诵经工作台。
2. 跟随**段级高亮**听读。
3. 到 **设置 → 朗读** 配置**播放内容矩阵**（原文 / 白话 / 英文）——与屏幕显示解耦。
4. 建议按需打开：静音外放、后台播放与锁屏播控、分章连读、播放时屏幕常亮。

### 6. 持诵学堂、念诵、抄经与功课

1. **学堂**（`isutra://study`）：背诵 / 填空 / 检视 / 测验，外加**寻经**。
2. **念诵**（`isutra://count`）：木鱼计数，目标 27 / 54 / 108 / 1080 或自定义，五音色，可选念诵实时活动。
3. **抄经**（`isutra://copy`，iOS）：PencilKit 描红——墨色 / 笔形、撤销、按句存稿、PNG / PDF 导出（笔迹仅本机）。
4. **功课**（`isutra://practice`）：早 / 晚清单与回向文；功课配置可走可选 iCloud。

### 7. 小组件、Siri、主屏快捷

1. 长按主屏幕 → **编辑** → **添加小组件** → 搜索「爱佛经」。
2. 可选：**今日一经 / 法语 / 持诵进度 / 收藏 / 今日念诵**。
3. 对 Siri 说今日一经、随机、诵经、收藏、学堂、寻经、念诵、抄经或搜索。
4. **设置 → 快捷**：配置主屏长按快捷；iOS 18+ 还可加控制中心控件。

### 8. 数据、同步与隐私

1. 语料在 App 内，**日常使用不需要网络**。抄经仅 iOS，笔迹本机保存。
2. **设置 → 数据 → iCloud 同步**（可选）：同步收藏、经单、浏览记录、掌握度、笔记、念诵偏好与功课配置——走**你的私有 iCloud**。
3. 「打赏开发者」为可选内购，**不解锁功能、不创建账号**。
4. 完整说明见 [隐私政策](privacy)。
