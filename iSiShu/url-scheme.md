<section lang="en" markdown="1">

iSiShu supports **`isishu://`** shortcut links.

## Common links

- `isishu://daily` — today’s Daily Saying
- `isishu://random` — random passage
- `isishu://passage?id=1001` — passage detail
- `isishu://recite?id=1001` — recite a passage
- `isishu://study` — Focused Study
- `isishu://hunt` — Hunt
- `isishu://favorites` — favorites
- `isishu://search?q=学而时习之` — search
- `isishu://collection?id=lunyu` — collection
- `isishu://theme?id=weizheng` — theme
- `isishu://notes` — notes
- `isishu://settings` — settings

</section>
