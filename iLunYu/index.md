**One saying a day. A lifetime of character.**

iLunYu (爱论语 / 愛論語) is an **immersive Analects learning studio** — not another plain text dump. **No account required.** All **512 chapters** of the *Analects* (twenty books) ship on your device with **bilingual alignment**, **vernacular**, selected commentary excerpts, and famous lines. **Recite** with paragraph highlighting; practice in the **Study classroom**; open a contextual **Daily Verse**. Export **share cards**, add **widgets**, optional **Reading Live Activity**, **Siri & Shortcuts**, and optional **iCloud**. **No ads. No tracking. Data Not Collected.**

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id6795595147) and open **iLunYu**.
2. Complete the **welcome guide** (brand → bilingual reading → recite → study → system features → privacy).
3. Replay anytime: **Settings → Help → Feature Guide**.
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Read today’s verse on Home

1. Open the **Home** tab.
2. The **Daily Verse** hero shows today’s chapter; tap to open detail.
3. Optional: turn on **Daily Verse notifications** in **Settings → Daily Verse** (local scheduling only).
4. Continue reading, famous lines, streaks, and shortcuts (including **Hunt**) are one tap away.

### 3. Browse & search

1. Open **Browse** (on by default; can be hidden in Settings).
2. Explore: **Analects → twenty books → ten themes** (仁德 / 礼乐 / 好学 …), **authors**, **famous lines**, and all chapters.
3. Use **Search** for titles, lines, and authors (Simplified / Traditional friendly).
4. Star chapters into **Favorites**; build personal **reading lists** (读经单). Favorites tab is **off by default** — still reachable from Home.

### 4. Bilingual reading & share cards

1. On detail, choose **bilingual / Chinese only / English only**; toggle vernacular and English independently.
2. Try **immersive reading**, vertical layout, font size, and segmented reading for long chapters.
3. Open **Share Card (论卡)** → preview → save to Photos (add-only) or system share.
4. Optional: enable **Reading Live Activity** on iPhone (must start in foreground).

### 5. Recite (诵读)

1. On detail, tap **Recite** — or open the Recitation studio.
2. Follow **paragraph highlighting** while listening.
3. In **Settings → Reading & Recitation**, set the **playback content matrix** (title / author / body × original / vernacular / English) — independent from what you *see*.
4. Optional: silent-mode playback, background audio + Now Playing, continuous play, keep screen on while speaking.

### 6. Study classroom (习礼学堂)

1. Open **Study** from Home / `ilunyu://study` / Shortcuts.
2. Modes: **Fade**, **Fill-blank**, **Meaning check**, **Quiz**; practice a single segment or a batch from favorites / lists.
3. Play **Hunt (寻章)** — keyword discovery game.
4. Track mastery levels and streaks.

### 7. Widgets, Siri & Home Screen shortcuts

1. Long-press Home Screen → **Edit Widgets** → add **Daily Verse / Famous Line / Study Progress / Favorites**.
2. Ask **Siri** for today’s verse, recite, random, favorites, or search.
3. Configure up to **4 Home Screen quick actions** in **Settings → Shortcuts**.
4. Control Center controls (iOS 18+) include Today / Random / Search / Study / Hunt and more.

### 8. Privacy & sync

1. Library, reading, recite (system TTS), study, widgets, and local notifications work **fully offline** after install.
2. Optional **iCloud Sync** (Settings → Data) mirrors favorites, lists, history, mastery, and streaks through **your private iCloud**.
3. Tip the developer (optional StoreKit) never unlocks paywalled content and never creates an account.

爱论语是一款**沉浸式论语品鉴与习礼工作台**——不是又一个原文列表。**无需注册登录**。全量内置《论语》二十篇 **512 章**（中英对照、白话、精选集注摘录与名句），安装后即可离线使用。**诵读**段级高亮；**习礼学堂**系统练习；结合节气/节日/季节的**每日一则**。导出**论卡**，支持主屏/锁屏**小组件**、可选**品读实时活动**、**Siri / 快捷指令**，以及可选 **iCloud**。**无广告、无追踪、不收集数据。**

## 保姆级上手教程

### 1. 第一次打开

1. 从 [App Store](https://apps.apple.com/app/id6795595147) 安装并打开**爱论语**。
2. 跟随欢迎引导（品牌 → 对照品鉴 → 诵读 → 学堂 → 系统能力 → 隐私）。
3. 之后可随时：**设置 → 帮助 → 功能引导** 重播。
4. **设置 → 帮助** 内还有**使用说明 / 小组件指南 / 快捷指南**。

### 2. 在首页看「每日一则」

1. 打开**首页** Tab。
2. Hero 卡片展示今日章句，点按进入详情。
3. 想每天提醒：到 **设置 → 每日一则** 打开通知并设定时间（**仅本机调度**）。
4. 首页还可继续阅读、看名句、打卡，并进入**寻章**等快捷入口。

### 3. 分类浏览与搜索

1. 打开**分类** Tab（默认开启，可在设置中隐藏）。
2. 路径：**书目《论语》→ 二十篇 → 十主题**（仁德 / 礼乐 / 好学 / 孝悌 / 君子 / 政事 / 诚信 / 交友 / 中庸 / 修身）→ 作者 / 名句 / 全部。
3. 用**搜索**查标题、正文、作者（简繁友好）。
4. 收藏章句，并整理个人**读经单**。收藏 Tab **默认关闭**，仍可从首页进入。

### 4. 对照品鉴与论卡

1. 详情页切换**对照 / 仅中 / 仅英**；白话与英译可分别开关。
2. 进入**沉浸阅读**，可调竖排、字号；长篇支持**分段阅读**。
3. 打开**论卡** → 预览 → 存入相册（仅「添加照片」）或系统分享。
4. iPhone 可打开**品读实时活动**（须在前台启动）。

### 5. 诵读（怎么听、怎么混读）

1. 在详情点**诵读**，或进入诵读工作台。
2. 跟随**段级高亮**听读。
3. 到 **设置 → 阅读与诵读** 调节语速 / 音调 / 音色，并设置**播放内容矩阵**（标题/作者/正文 × 原文/白话/英文）——与「屏幕上显示什么」相互独立，可混读多语种。
4. 建议按需打开：静音外放、后台播放与锁屏播控、连续播放、播放时屏幕常亮。

### 6. 习礼学堂（怎么练到掌握）

1. 从首页或 `ilunyu://study` 进入。
2. 四种模式：**渐隐 / 填空 / 经义检测 / 测验**；可练本段，也可从收藏 / 读经单批量练习。
3. 玩玩**寻章**小游戏，按关键字找回章句。
4. 掌握度分级配合打卡连续天数。

### 7. 小组件、Siri、主屏快捷

1. 长按主屏幕 → **编辑** → **添加小组件** → 搜索「爱论语」。
2. 可选：**每日一则 / 名句 / 掌握进度 / 收藏**。
3. 对 Siri 说今日一则、随机、诵读、收藏或搜索。
4. **设置 → 快捷**：最多 4 个主屏长按快捷；iOS 18+ 还可加控制中心控件（含寻章）。

### 8. 数据、同步与隐私

1. 语料在 App 内，**日常使用不需要网络**。
2. **设置 → 数据 → iCloud 同步**（可选）：同步收藏、读经单、浏览记录、掌握度与打卡——走**你的私有 iCloud**。
3. 「打赏开发者」为可选内购，**不解锁功能、不创建账号**。
4. 完整说明见 [隐私政策](privacy)。
