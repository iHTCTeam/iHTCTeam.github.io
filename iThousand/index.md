**One character a day. A thousand for a lifetime.**

iThousand (爱千字文 / 愛千字文) is an **immersive primer literacy studio** — not another plain text dump. **No account required.** **122** passages ship on your device: *Thousand Character Classic* (stanza groups), *San Zi Jing*, *Hundred Family Surnames*, and *Di Zi Gui*, with **bilingual reading**, **vernacular**, **pinyin**, **1661** character cards with **stroke-order animation**, and **104** famous lines. **Recite** with line highlighting; train in **Primer Hall**; play **Character Hunt**. Start with a contextual **Daily Line**. Export **share cards** (千卡), add **five widget types**, optional **Reading Live Activity**, **Siri & Shortcuts**, and optional **iCloud**. Library text is curated from public web sources. **No ads. No tracking. Data Not Collected.**

**At a glance:** 122 passages · 1661 stroke cards · bilingual read · recite · Primer Hall · Hunt · Daily Line · 104 lines · 千卡 · 5 widgets · Control Center · `ithousand://` · EN / 简 / 繁.

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id6796010801) and open **iThousand**.
2. Complete the **6-page welcome guide** (brand → bilingual reading → character cards → recite / Primer Hall → Daily Line & widgets → privacy).
3. Replay anytime: **Settings → Help → Feature Guide** (`ithousand://feature-guide`).
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Read today’s line on Home

1. Open the **Home** tab.
2. The **Daily Line** hero shows today’s passage; tap to open detail.
3. Optional: turn on **Daily Line notifications** in Settings (local scheduling only; festivals follow the lunar calendar).
4. Continue reading, famous lines, streaks, and shortcuts (including **Hunt** and **character cards**) are one tap away.

### 3. Browse & search

1. Open **Browse** (on by default; can be hidden in Settings).
2. Explore four primer collections, themes, authors, famous lines, and all passages.
3. Use **Search** for titles, lines, characters, and authors (Simplified / Traditional friendly).
4. Star passages into **Favorites**; bookmark hard characters into **Saved Characters**; build personal **lists** (千单). Favorites tab is **on by default**.

### 4. Bilingual reading, character cards & share cards

1. On detail, choose **bilingual / Chinese only / English only**; toggle vernacular, English, and pinyin independently.
2. Tap a character to open its **card** (sound, meaning, radical, stroke count) and play **stroke-order tracing**.
3. Try **immersive reading**, font scale, and **segmented pages** for longer stretches.
4. Open **Share Card (千卡)** → pick style / ratio → save to Photos (add-only) or system share. Character cards can be shared as images too.

### 5. Recite (诵读)

1. On detail, tap **Recite** — or open the Recitation studio.
2. Follow **line-level highlighting** while listening.
3. In **Settings → Recitation**, set the **playback content matrix** (title / author / body × original / vernacular / English) — independent from what you *see*.
4. Optional: silent-mode playback, background audio + Now Playing, continuous play, keep screen on, Reading Live Activity (start in foreground).

### 6. Primer Hall & Character Hunt (蒙学堂 · 寻字)

1. Open **Study** from Home / `ithousand://study` / Shortcuts.
2. Modes: **Recitation**, **Fill-blank**, **Self-check**, **Quiz**; plus **Hunt (寻字)**.
3. Track mastery levels; practice a single passage or a batch from favorites / lists.
4. Bookmark hard characters from a passage (`ithousand://passage?id=1&open=characters`) or `ithousand://characters`.

### 7. Widgets, Siri & Home Screen shortcuts

1. Long-press Home Screen → **Edit Widgets** → add **Daily Line / Famous Line / Study Progress / Favorites / Saved Characters**.
2. Ask **Siri** for today’s line, recite, random, favorites, study, hunt, characters, or search.
3. Configure Home Screen quick actions in **Settings → Shortcuts**.
4. Control Center controls (iOS 18+) include Today / Random / Search / Study / Hunt / Characters and more.

### 8. Privacy & sync

1. Library, character cards, reading, recite (system TTS), study, widgets, and local notifications work **fully offline** after install.
2. Optional **iCloud Sync** mirrors favorites, lists, history, mastery, streaks, notes, and saved characters through **your private iCloud**.
3. Tip the developer (optional StoreKit) never unlocks paywalled content and never creates an account.

## 保姆级上手教程

### 1. 第一次打开

1. 从 [App Store](https://apps.apple.com/app/id6796010801) 安装并打开**爱千字文**。
2. 跟随 **6 页欢迎引导**（品牌 → 对照品读 → 字卡 → 诵读 / 蒙学堂 → 每日一句与小组件 → 隐私）。
3. 之后可随时：**设置 → 帮助 → 功能引导** 重播。
4. **设置 → 帮助** 内还有**使用说明 / 小组件指南 / 快捷指南**。

### 2. 在首页看「每日一句」

1. 打开**首页** Tab。
2. Hero 卡片展示今日篇目，点按进入详情。
3. 想每天提醒：到设置打开每日通知并设定时间（**仅本机调度**；节日按**农历**）。
4. 首页还可继续阅读、看名句、打卡，并进入**寻字**与字卡入口。

### 3. 分类浏览与搜索

1. 打开**分类** Tab（默认开启，可在设置中隐藏）。
2. 浏览四部蒙学合集、主题、作者、名句与全部篇目。
3. 用**搜索**查标题、正文、单字与作者（简繁友好）。
4. 收藏篇目，生字收入**生字本**，并整理个人**千单**。收藏 Tab **默认开启**。

### 4. 对照品读、字卡与千卡

1. 详情页切换**对照 / 仅中 / 仅英**；白话、英译与拼音可分别开关。
2. 点字打开**字卡**（音义、部首、笔画）并播放**笔顺描红**。
3. 进入**沉浸阅读**，可调字号；长篇支持**分段阅读**。
4. 打开**千卡** → 预览 → 存入相册（仅「添加照片」）或系统分享；字卡也可导出图片。

### 5. 诵读（怎么听、怎么混读）

1. 在详情点**诵读**，或进入诵读工作台。
2. 跟随**句级高亮**听读。
3. 到 **设置 → 诵读** 设置**播放内容矩阵**（标题/作者/正文 × 原文/白话/英文）——与屏幕显示解耦，可混读多语种。
4. 建议按需打开：静音外放、后台播放与锁屏播控、连续播放、播放时屏幕常亮、品读实时活动（须在前台启动）。

### 6. 蒙学堂与寻字

1. 从首页或 `ithousand://study` 进入学堂。
2. 四种模式：**背诵 / 填空 / 自测 / 测验**；另有**寻字**。
3. 掌握度分级；可练单篇，也可从收藏 / 千单批量练习。
4. 本篇字表：`ithousand://passage?id=1&open=characters`；字库：`ithousand://characters`。

### 7. 小组件、Siri、主屏快捷

1. 长按主屏幕 → **编辑** → **添加小组件** → 搜索「爱千字文」。
2. 可选：**每日一句 / 名句 / 掌握进度 / 收藏 / 生字**。
3. 对 Siri 说今日一句、随机、诵读、收藏、学堂、寻字、字卡或搜索。
4. **设置 → 快捷**：配置主屏长按快捷；iOS 18+ 还可加控制中心控件。

### 8. 数据、同步与隐私

1. 语料与字卡在 App 内，**日常使用不需要网络**。
2. **设置 → 数据 → iCloud 同步**（可选）：同步收藏、千单、浏览记录、掌握度、打卡、笔记与生字——走**你的私有 iCloud**。
3. 「打赏开发者」为可选内购，**不解锁功能、不创建账号**。
4. 完整说明见 [隐私政策](privacy)。
