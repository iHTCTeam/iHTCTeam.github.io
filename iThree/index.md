**Three characters at a time. A foundation for a lifetime.**

iThree (爱三字经 / 愛三字經) is an **immersive San Zi Jing learning studio** — not another plain text dump. **No account required.** All **48 passages** ship on your device with **character pinyin**, **vernacular**, **English**, **21 stories**, **16 classic indexes**, **21 dynasties**, and **32 famous lines**. **Read** side by side; **recite** with line highlighting; practice in **study modes**; open a contextual **Daily Line**. Export **share cards**, add **widgets**, optional **Reading Live Activity**, **Siri & Shortcuts**, and optional **iCloud**. **No ads. No tracking. Data Not Collected.**

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id6796002326) and open **iThree**.
2. Complete the **welcome guide** (brand → bilingual reading → recite → study → system features → privacy).
3. Replay anytime: **Settings → Help → Feature Guide** (`ithree://feature-guide`).
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Read today’s line on Home

1. Open the **Home** tab.
2. The **Daily Line** hero shows today’s passage; tap to open detail.
3. Optional: turn on **Daily Line notifications** in Settings (local scheduling only; festivals follow the lunar calendar).
4. Continue reading, famous lines, streaks, and shortcuts (including **Hunt**) are one tap away.

### 3. Browse & search

1. Open **Browse** (can be hidden in Settings).
2. Explore **six chapters**, **tags**, **stories**, **classic books**, **dynasties**, **famous lines**, and all passages. Collection pages show a short intro and a collapsible essay.
3. Use **Search** for titles, lines, stories, and authors (Simplified / Traditional friendly).
4. Star passages into **Favorites**; favorite **stories** separately; build personal **line lists** (句单). Favorites tab is **on by default**.

### 4. Bilingual reading & share cards

1. On detail, choose **bilingual / Chinese only / English only**; toggle **pinyin**, vernacular, English, and notes independently.
2. Try **vertical reading**, centering, font scale, immersive mode, and **segmented pages** for longer stretches.
3. Open **Share Card** → pick style / ratio and whether to include vernacular, English, or pinyin → save to Photos (add-only) or system share.
4. Optional: enable **Reading Live Activity** on iPhone (must start in foreground).

### 5. Recite (诵读)

1. On detail, tap **Recite** — or open the Recitation studio.
2. Follow **line-level highlighting** while listening.
3. In **Settings → Recitation**, set the **playback content matrix** (title / author / body × original / vernacular / English) — independent from what you *see*.
4. Optional: silent-mode playback, background audio + Now Playing, continuous play, keep screen on while speaking.

### 6. Study classroom (蒙学)

1. Open **Study** from Home / `ithree://study` / Shortcuts for the four modes menu.
2. Modes: **Recitation**, **Fill-blank**, **Self-check**, **Quiz** (`ithree://quiz` jumps straight into today’s quiz).
3. Play **Hunt (寻句 / 一字寻句)** via Home, Control Center, or `ithree://hunt`.
4. Batch practice from favorites, line lists, or mastered items; track mastery levels and streaks.

### 7. Widgets, Siri & Home Screen shortcuts

1. Long-press Home Screen → **Edit Widgets** → add **Daily Line / Famous Line / Study Progress / Favorites** (Daily Line supports paper styles).
2. Ask **Siri** for today’s line, recite, random, favorites, hunt, or search.
3. Configure Home Screen quick actions in **Settings → Shortcuts**.
4. Control Center controls (iOS 18+) include Today / Random / Search / Study / Hunt and more.

### 8. Privacy & sync

1. Library, reading, recite (system TTS), study, widgets, and local notifications work **fully offline** after install.
2. Optional **iCloud Sync** mirrors favorites (including story favorites), lists, history, mastery, and streaks through **your private iCloud**.
3. Tip the developer (optional StoreKit) never unlocks paywalled content and never creates an account.

## 保姆级上手教程

### 1. 第一次打开

1. 从 [App Store](https://apps.apple.com/app/id6796002326) 安装并打开**爱三字经**。
2. 跟随欢迎引导（品牌 → 对照品读 → 诵读 → 蒙学 → 系统能力 → 隐私）。
3. 之后可随时：**设置 → 帮助 → 功能引导** 重播（`ithree://feature-guide`）。
4. **设置 → 帮助** 内还有**使用说明 / 小组件指南 / 快捷指南**。

### 2. 在首页看「每日一句」

1. 打开**首页** Tab。
2. Hero 卡片展示今日段落，点按进入详情。
3. 想每天提醒：到设置打开每日通知并设定时间（**仅本机调度**；节日按**农历**）。
4. 首页还可继续阅读、看名句、打卡，并进入**寻句**等快捷入口。

### 3. 分类浏览与搜索

1. 打开**分类** Tab（可在设置中隐藏）。
2. 浏览**六章 / 标签 / 典故 / 典籍 / 朝代 / 名句 / 全部**；合集页有短导读与可展开长文。
3. 用**搜索**查段落、典故与典籍（简繁友好）。
4. 收藏段落，也可单独收藏**典故**；整理个人**句单**。收藏 Tab **默认开启**。

### 4. 对照品读与分享卡

1. 详情页切换**对照 / 仅中 / 仅英**；**拼音**、白话、英译、注释可分别开关。
2. 可开竖排、原文居中、字号缩放、沉浸阅读；长文支持**分段翻页**。
3. 打开**分享卡** → 选风格 / 比例，以及是否附白话、英译、拼音 → 存入相册（仅「添加照片」）或系统分享。
4. iPhone 可打开**品读实时活动**（须在前台启动）。

### 5. 诵读（怎么听、怎么混读）

1. 在详情点**诵读**，或进入诵读工作台。
2. 跟随**句级高亮**听读。
3. 到 **设置 → 朗读** 设置**播放内容矩阵**（标题/作者/正文 × 原文/白话/英文）——与屏幕显示解耦。
4. 建议按需打开：静音外放、后台播放与锁屏播控、连续播放、播放时屏幕常亮。

### 6. 蒙学学堂（怎么练到掌握）

1. 从首页或 `ithree://study` 进入四模式菜单。
2. 模式：**背诵 / 填空 / 自测对照 / 测验**（`ithree://quiz` 可直达今日测验）。
3. 玩玩**寻句（一字寻句）**：首页 / 控制中心 / `ithree://hunt`。
4. 可从收藏、句单或已掌握批量练习；掌握度分级配合打卡。

### 7. 小组件、Siri、主屏快捷

1. 长按主屏幕 → **编辑** → **添加小组件** → 搜索「爱三字经」。
2. 可选：**每日一句 / 名句 / 掌握进度 / 收藏**（每日一句可配笺纸样式）。
3. 对 Siri 说今日一句、随机、诵读、收藏、寻句或搜索。
4. **设置 → 快捷**：配置主屏长按快捷；iOS 18+ 还可加控制中心控件。

### 8. 数据、同步与隐私

1. 语料在 App 内，**日常使用不需要网络**。
2. **设置 → 数据 → iCloud 同步**（可选）：同步段收藏、典故收藏、句单、浏览记录、掌握度与打卡——走**你的私有 iCloud**。
3. 「打赏开发者」为可选内购，**不解锁功能、不创建账号**。
4. 完整说明见 [隐私政策](privacy)。
